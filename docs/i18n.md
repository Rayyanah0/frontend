# Internationalization (#116)

The app uses [next-intl](https://next-intl.dev) with locale routing. The
shipped locales are **en** (source), **es**, and **pt**.

## Routing

- All pages live under `src/app/[locale]/`. English is unprefixed
  (`/options`). Other locales are prefixed (`/es/options`, `/pt/options`).
  `localePrefix: "as-needed"` is set in `src/i18n/routing.ts`.
- `src/middleware.ts` picks the locale from the `NEXT_LOCALE` cookie first,
  then `Accept-Language`. The `LocaleSwitcher` (in the header and in
  Settings) sets the cookie. The middleware also emits hreflang `Link`
  headers for every URL. The layout adds `<link rel="alternate" hreflang>`
  tags plus `x-default`.
- For internal links, use `Link`, `usePathname`, and `useRouter` from
  `src/i18n/navigation.ts`. The `next/link` versions don't keep the locale
  prefix.

## Using messages

```tsx
// Client component
const t = useTranslations("home");
t("example", { strike: fmtK(k) });
t.rich("watchlistEmpty", { link: (c) => <Link href="/options">{c}</Link> });

// Server component
const t = await getTranslations("notFound");
```

Catalogs are in `messages/<locale>.json`, with keys namespaced by area
(`nav`, `header`, `session`, `clearSign`, `home`, `settings`, …). Messages
use ICU syntax for arguments, plurals, and rich-text tags.

## Numbers and dates

- **Numbers.** Use `useLocaleFormatters()` (`src/lib/i18n/useLocaleFormatters.ts`).
  It wraps the instrument-aware formatters in `src/lib/format.ts`, bound to
  the locale's BCP 47 tag. Separators and currency symbols are localized.
  Decimal places always come from the instrument registry, so financial
  precision doesn't change with locale.
- **Dates.** Use next-intl's `useFormatter()` / `format.dateTime(d, "expiry")`.
  `timeZone` is pinned to `UTC` in `src/i18n/request.ts` and on the client
  provider, so the server and client render identical text. This avoids
  hydration mismatches.

## Translation workflow (Crowdin / Weblate)

1. Developers add English strings to `messages/en.json` only.
2. `crowdin.yml` uploads `en.json` as the source (`crowdin upload sources`).
   Translators work in Crowdin, whose ICU-aware editor keeps `{args}`,
   plurals, and `<tags>` intact.
3. `crowdin download` writes `messages/<locale>.json`. Open a PR.
4. Weblate works the same way: add a component with the "JSON nested
   structure" format, `messages/en.json` as the template, and
   `messages/*.json` as the file mask.

To add a locale, add it to `locales`, `INTL_LOCALE`, and `LOCALE_LABELS` in
`src/i18n/routing.ts` and create `messages/<locale>.json`.

## CI

`npm run i18n:check` (`scripts/i18n-check.mjs`, run by
`.github/workflows/i18n.yml`) fails on missing, extra, or empty keys, and on
placeholder or tag drift between a locale and `en.json`. The logic lives in
`src/lib/i18n/keys.cjs` and is unit-tested in
`src/lib/i18n/__tests__/keys.test.ts`, which also asserts that the shipped
catalogs are complete. `tests/e2e/i18n.spec.ts` smoke-runs every locale with
Playwright. It checks `lang`, the translated content, hreflang,
Accept-Language redirects, cookie persistence, and that there are no
hydration or missing-message errors.

## Status and follow-ups

String extraction currently covers the layout metadata, the app header and
navigation, the session banner, the confirm dialog, the clear-signing
summary, the home page, settings, and not-found. The remaining terminal
pages and components (options, portfolio, history, calendar, vaults,
grants, referrals, governance, community, stats, and their panels) still
render English literals. Extract them namespace by namespace with the same
pattern. The CI check covers every new key automatically.

- **Per-route bundles.** The layout passes every namespace to
  `NextIntlClientProvider`. Once more namespaces exist, give each route
  segment its own provider with `pick(messages, [...])`.
- **Text expansion.** Spanish and Portuguese run about 20–30% longer. Dense
  chain tables keep headers short (column abbreviations are translated as
  abbreviations). Review screenshots for each locale before merging new
  table strings.
- **RTL.** Out of scope. A layout audit is required before adding `ar`/`he`.
